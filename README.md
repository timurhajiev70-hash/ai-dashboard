# AI Dashboard «Мои ИИ системы»

Локальная панель: какие ИИ-системы у вас есть, что они умеют, какие инструменты к ним подключены и кому отдать задачу.
Без npm-зависимостей, один Node.js-сервер + одна страница. Подробности: [docs/SPEC.md](docs/SPEC.md).

## Требования

| Что | Как проверить |
|---|---|
| Node.js ≥ 18 | `node -v` |
| macOS (скрипты `.sh`, автозапуск через launchd) | Терминал |

## Первый запуск

```bash
cd ai-dashboard
cp data/.env.example data/.env      # затем откройте data/.env и задайте PASSWORD=...
./scripts/start.sh
```

Откройте http://127.0.0.1:8787

Если `chmod` не выставлен: `chmod +x scripts/*.sh`.

## Настройки `data/.env`

| Переменная | Что делает |
|---|---|
| `PASSWORD` | Пароль входа. Смена пароля завершает все сессии |
| `PORT` | Порт (по умолчанию 8787) |
| `HOST` | `127.0.0.1` — только этот Mac; `0.0.0.0` — доступ из сети |
| `ALLOWED_HOSTS` | Доп. имена в адресной строке (через запятую), например `mac.tail1234.ts.net`. Без этого чужое имя → ошибка 421 |
| `CHECK_ALLOW_PRIVATE_HOSTS` | Хосты, которые «Проверить сайт» может проверять во внутренней сети. Для «Мира»: `localhost` |

Права на файл: `chmod 600 data/.env` (иначе предупреждение в `data/server.log`).

## Язык интерфейса

Настройки → «Язык интерфейса»: **Русский** / **Deutsch**. Выбор запоминается в браузере и в `config.json`. Строки — `public/locales/ru.json`, `de.json`. Ваши данные и объяснения подбора остаются на русском.

## Управление

| Действие | Команда |
|---|---|
| Запуск | `./scripts/start.sh` |
| Остановка | `./scripts/stop.sh` |
| Перезапуск | `./scripts/restart.sh` |
| Автозапуск при входе в систему | `./scripts/install-launchd.sh` |
| Убрать автозапуск | `./scripts/uninstall-launchd.sh` |

## Доступ с телефона (Android)

| Шаг | Что сделать |
|---|---|
| 1 | В `data/.env` указать `HOST=0.0.0.0` и обязательно `PASSWORD=...` |
| 2 | Перезапустить: `./scripts/restart.sh` |
| 3 | Установить Tailscale или WireGuard на Mac и телефон |
| 4 | На телефоне открыть `http://<ip-mac>:8787` (для Tailscale это его адрес Mac) |

Порт на роутере наружу не открывайте: используйте Tailscale или WireGuard.

## Где лежат данные

| Что | Где |
|---|---|
| Вся конфигурация (системы, инструменты, связи, правила) | `data/config.json` (создаётся из `data/config.default.json` при первом запуске) |
| Пароль, порт, адрес | `data/.env` (не входит в экспорт) |
| Сессии | `data/.sessions.json` |
| Лог запросов (метод, путь, код, время) | `data/server.log` |

## Экспорт и импорт

| Действие | Где |
|---|---|
| Экспорт | Настройки → «Экспорт» (скачивается `config.json` без секретов) |
| Импорт | Настройки → выбрать файл → «заменить» или «слить» (слияние по id) |

## Пометка «ДЕМО»

Стартовые данные помечены «ДЕМО»: это примеры, а не проверенная информация (статусы не проверены, `checkedAt` пуст).

Как убрать демо-данные:

| Способ | Как |
|---|---|
| Вручную | Отредактировать или удалить карточки, связи и правила; после правки пометка `demo` снимается |
| Своя конфигурация | Настройки → Импорт → «заменить» своим `config.json` |

## Безопасность

| Правило | Пояснение |
|---|---|
| Секреты только в `data/.env` | Не пишутся в `config.json`, экспорт, логи; не отдаются в браузер |
| Пароль обязателен при `HOST` ≠ 127.0.0.1 | Без пароля на 127.0.0.1 авторизация выключена |
| Проверка заголовков Host/Origin | Чужое имя → 421, запрос с чужого сайта → 403 |
| «Проверить сайт» | Внутренние адреса запрещены, кроме `CHECK_ALLOW_PRIVATE_HOSTS` |
| Внешний доступ | Только через Tailscale/WireGuard |
| Не публикуйте `data/` | В `.env` и `.sessions.json` секреты |

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Порт занят | Узнать процесс: `lsof -i :8787`; остановить его или поменять `PORT=` в `data/.env` и перезапустить |
| Забыли пароль | Открыть `data/.env`, задать новый `PASSWORD=...`, выполнить `./scripts/restart.sh` |
| Не запускается, `node: command not found` | Установить Node.js ≥ 18, проверить `node -v` |
| Телефон не открывает страницу | Проверить `HOST=0.0.0.0`, пароль, что Tailscale/WireGuard активны на обоих устройствах |
| Ошибка 421 | Открываете по имени (MagicDNS и т.п.) — добавьте его в `ALLOWED_HOSTS` |
| «Проверка внутренних адресов запрещена» у «Мира» | `CHECK_ALLOW_PRIVATE_HOSTS=localhost` в `data/.env`, перезапуск |
| Что-то странное | Смотреть `data/server.log` |
