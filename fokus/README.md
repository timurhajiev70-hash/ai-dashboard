# Fokus — личный дневник задач с приоритетами

Не список дел, а инструмент выбора: что делать первым. Каждая задача проходит мастер из 6 вопросов,
получает балл 0–100 и группу (матрица Эйзенхауэра + баллы). В день — не больше 3 главных задач.
Python (только стандартная библиотека) + SQLite + одна HTML-страница, без внешних зависимостей. Спецификация и правила: [AGENTS.md](AGENTS.md).

## Требования

| Что | Как проверить |
|---|---|
| macOS (лаунчер `Fokus.command`, Терминал) | Finder → двойной клик |
| Python 3 ≥ 3.9 — системный, входит в Command Line Tools | `python3 --version`. Если macOS предлагает установить инструменты — `xcode-select --install` |

Ничего устанавливать не нужно: ни pip, ни npm, ни Homebrew.

## Первый запуск

| Шаг | Что сделать |
|---|---|
| 1 | Положить папку проекта куда угодно, например `~/Projects/fokus` |
| 2 | Двойной клик по `Fokus.command` — откроется окно Терминала и браузер |
| 3 | Адрес: http://127.0.0.1:4321 (окно Терминала не закрывать — в нём работает сервер) |

Ярлык на рабочий стол (символическая ссылка, не копия — лаунчер разрешает её и работает в папке проекта):

```bash
ln -s ~/Projects/fokus/Fokus.command ~/Desktop/Fokus.command
```

Из Терминала то же самое: `cd ~/Projects/fokus && ./Fokus.command` или просто `python3 server.py`.

Что делает лаунчер: переходит в папку проекта → если Fokus уже запущен, только открывает браузер → проверяет Python 3 ≥ 3.9 → запускает `server.py` (тот сам делает копию базы) → ждёт ответа `/api/health` до 5 с → открывает браузер → ждёт, пока сервер работает.

## Остановка

| Действие | Как |
|---|---|
| Остановить | `Ctrl+C` в окне Терминала или закрыть это окно |
| Fokus уже запущен, нажали ярлык ещё раз | Второй сервер не стартует — просто откроется браузер |

## Где лежат данные

| Что | Где |
|---|---|
| База (все задачи, журнал изменений, настройки) | `data/fokus.db` (SQLite, WAL) |
| Копии базы — при каждом запуске сервера, хранятся 10 последних | `data/backups/fokus-YYYYMMDD-HHMMSS.db` |
| Интерфейс | `static/index.html` |

Папка `data/` в `.gitignore`. Вернуть старую копию: остановить Fokus, заменить `data/fokus.db` файлом из `data/backups/`.

## Переменные окружения

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `FOKUS_PORT` | Порт сервера | `4321` |
| `FOKUS_DB` | Путь к базе | `data/fokus.db` рядом со скриптом |
| `FOKUS_TODAY` | Дата «сегодня» `YYYY-MM-DD` — для тестов и проверок переноса | локальная дата |
| `FOKUS_PYTHON` | Только лаунчер: какой интерпретатор запускать вместо `python3` из PATH | `python3` |
| `FOKUS_OPEN` | Только лаунчер: команда открытия браузера вместо `open` (в тестах `true`) | `open` |

Пример: `FOKUS_PORT=4322 ./Fokus.command`.

## Тесты

```bash
cd ~/Projects/fokus
python3 -m unittest discover -s tests          # всё
python3 -m unittest tests.test_launcher -v     # один файл
```

| Файл | Что проверяет |
|---|---|
| `tests/test_engine.py`, `test_reference.py` | движок: баллы, группы, эталонные задачи из AGENTS.md §5.4 |
| `tests/test_db.py` | схема, CRUD, журнал, бэкап, настройки |
| `tests/test_api.py` | HTTP API |
| `tests/test_launcher.py` | `Fokus.command`: синтаксис, права, поведение без Python, ярлык-ссылка, реальный запуск сервера |

В тестах только обезличенные данные.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| «Сервер завершился сразу после запуска» / порт занят | Узнать процесс: `lsof -i :4321`; остановить его или запустить с другим портом: `FOKUS_PORT=4322 ./Fokus.command` |
| «Не найден Python 3» или macOS предлагает установить инструменты разработчика | В Терминале: `xcode-select --install`, дождаться установки, запустить снова |
| «Fokus.command не может быть открыт» / открывается как текст | В Терминале: `chmod +x ~/Projects/fokus/Fokus.command`. Если macOS жалуется на неизвестного разработчика: правый клик → «Открыть», либо Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно», либо `xattr -d com.apple.quarantine Fokus.command` |
| «Рядом с Fokus.command нет server.py» | Ярлык на рабочем столе должен быть ссылкой (`ln -s …`), а не копией файла; либо запускать `Fokus.command` из папки проекта |
| Браузер пишет «Сервер не отвечает» | Окно Терминала закрыто — запустить `Fokus.command` снова |
| Страница открылась пустой | Подождать пару секунд и обновить: сервер стартовал дольше 5 с |
| Хочу начать с чистой базы | Остановить Fokus, переименовать `data/fokus.db` (копии остаются в `data/backups/`) |
| Как остановить | `Ctrl+C` в окне Терминала или закрыть окно |

## Правила

| Правило | Пояснение |
|---|---|
| Пациенты — только номера tomedo | Никаких имён в названиях, заметках, журнале и тестах. Подсказка есть в поле названия |
| Интеграции в v1 нет | Телефон, Мир, Todoist, календарь — позже |
| Сервер только локальный | Слушает 127.0.0.1; запрос с чужого сайта (другой `Origin`) → 403 |
| Удаление мягкое | Задача получает `status=deleted`, журнал сохраняется |
| Единственный источник правды | [AGENTS.md](AGENTS.md): если код расходится с ним — ошибка в коде |
