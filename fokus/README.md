# Fokus — личный дневник задач с приоритетами

Не список дел, а инструмент выбора: что делать первым. Каждая задача проходит мастер из 6 вопросов,
получает балл 0–100 и группу (матрица Эйзенхауэра + баллы). В день — не больше 3 главных задач.
Версия 2: интерфейс в стиле Todoist, проекты, «Входящие», события Google Календаря, приложение `Fokus.app`.
Python (только стандартная библиотека) + SQLite + одна HTML-страница, без внешних зависимостей. Спецификация и правила: [AGENTS.md](AGENTS.md).

## Требования

| Что | Как проверить |
|---|---|
| macOS 11+ | `Fokus.app` — двойной клик в Finder; `Fokus.command` — то же через Терминал |
| Python 3 ≥ 3.9 — системный, входит в Command Line Tools | `python3 --version`. Если macOS предлагает установить инструменты — `xcode-select --install` |
| Браузер | любой. Если есть Google Chrome, Chromium, Brave, Microsoft Edge или Arc — Fokus откроется отдельным окном без адресной строки, иначе вкладкой в браузере по умолчанию |

Ничего устанавливать не нужно: ни pip, ни npm, ни Homebrew.

## Запуск как приложение

| Шаг | Что сделать |
|---|---|
| 1 | Положить папку проекта куда угодно, например `~/Projects/fokus` (`Fokus.app` лежит внутри неё и должен там остаться) |
| 2 | Двойной клик по `Fokus.app` — Терминал не открывается, через 1–2 с появляется окно Fokus |
| 3 | Ярлык в Dock: перетащить `Fokus.app` в Dock (или правый клик по иконке в Dock → Параметры → Оставить в Dock) |
| 4 | Ярлык на рабочий стол: `ln -s ~/Projects/fokus/Fokus.app ~/Desktop/Fokus.app` (ссылка, не копия) |

| Ситуация | Что происходит |
|---|---|
| Скачали zip с GitHub, macOS пишет «не удаётся проверить разработчика» | Карантин. Один раз: правый клик по `Fokus.app` → «Открыть» → «Открыть». При `git clone` карантина нет |
| Есть Chrome / Brave / Edge / Arc | Окно без адресной строки (`--app=`), 1200×820, как отдельная программа. Выбрать браузер принудительно: `FOKUS_BROWSER="Brave Browser"`, обычная вкладка — `FOKUS_BROWSER=default` |
| Только Safari | Откроется вкладка. Альтернатива «как приложение»: Safari → открыть http://127.0.0.1:4321 → Файл → «Добавить в Dock» |
| Нажали на иконку ещё раз | Второй сервер не стартует — только откроется окно |
| Нет Python 3 | Диалог «Нужен Python 3: откройте Терминал и выполните xcode-select --install» |
| Сервер не поднялся (например, порт занят) | Диалог с последней строкой `data/server.log` |

Что делает `Fokus.app` (`Contents/MacOS/Fokus`, bash): находит папку проекта (три уровня выше, ссылки разрешает) → если Fokus уже отвечает на `/api/health`, только открывает окно → проверяет Python 3 ≥ 3.9 → запускает `server.py` в фоне (`nohup`, вывод в `data/server.log`; сервер сам делает копию базы) → ждёт `/api/health` до 8 с → открывает окно → завершается. Сервер живёт сам, пока его не выключить.

Через Терминал: двойной клик по `Fokus.command` (окно Терминала остаётся открытым, пока работает сервер; `Ctrl+C` — остановить) или `cd ~/Projects/fokus && python3 server.py`. Адрес в любом случае: http://127.0.0.1:4321.

## Остановка

| Действие | Как |
|---|---|
| Выключить Fokus | В приложении: Настройки → кнопка «Выключить Fokus» (`POST /api/shutdown`) |
| То же из Терминала | Двойной клик по `Fokus.command` → «Fokus уже работает» → клавиша `s` (остановить); `o` — открыть браузер, `q` — выход |
| Сервер, запущенный через `Fokus.command` | `Ctrl+C` в окне Терминала или закрыть окно |
| Закрыли окно браузера | Сервер продолжает работать — это нормально; следующий клик по иконке просто откроет окно снова |

## Где лежат данные

| Что | Где |
|---|---|
| База (все задачи, проекты, журнал изменений, настройки, кэш календаря) | `data/fokus.db` (SQLite, WAL) |
| Копии базы — при каждом запуске сервера, хранятся 10 последних | `data/backups/fokus-YYYYMMDD-HHMMSS.db` |
| Вывод сервера, запущенного через `Fokus.app` или MCP | `data/server.log` |
| Интерфейс | `static/index.html` |
| Иконка приложения | `Fokus.app/Contents/Resources/Fokus.icns` (генерируется: `python3 tools/make_icon.py`) |

Папка `data/` в `.gitignore`. Вернуть старую копию: остановить Fokus, заменить `data/fokus.db` файлом из `data/backups/`.

## Переменные окружения

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `FOKUS_PORT` | Порт сервера | `4321` |
| `FOKUS_DB` | Путь к базе | `data/fokus.db` рядом со скриптом |
| `FOKUS_TODAY` | Дата «сегодня» `YYYY-MM-DD` — для тестов и проверок переноса | локальная дата |
| `FOKUS_BROWSER` | Только `Fokus.app`: имя браузера для окна без адресной строки (`"Google Chrome"`, `"Brave Browser"`, …) или `default` — обычная вкладка | перебор Chrome → Chromium → Brave → Edge → Arc, иначе вкладка |
| `FOKUS_PYTHON` | Только лаунчеры: какой интерпретатор запускать вместо `python3` из PATH | `python3` |
| `FOKUS_OPEN` | Только лаунчеры: команда открытия браузера вместо `open` (в тестах `true`) | `open` |

Пример: `FOKUS_PORT=4322 ./Fokus.command`.

## Google Календарь

Fokus показывает события календаря в «Сегодня» и «Предстоящие». Подключение — по секретному iCal-адресу, без входа в Google и без OAuth.

| Шаг | Что сделать |
|---|---|
| 1 | Открыть Google Календарь в браузере → ⚙ (справа вверху) → «Настройки» |
| 2 | Слева в списке «Настройки моих календарей» выбрать нужный календарь |
| 3 | Прокрутить до раздела «Интеграция календаря» |
| 4 | Скопировать «Секретный адрес в формате iCal» (`https://calendar.google.com/calendar/ical/…/private-…/basic.ics`) |
| 5 | Fokus → Настройки → «Google Календарь» → вставить адрес (несколько календарей — по одному в строке) → «Проверить и обновить» |

| Важно | |
|---|---|
| Адрес = пароль | Секретный адрес даёт полный доступ на чтение календаря. Не пересылать, не публиковать. Если утёк — в тех же настройках Google «Сбросить» адрес и вставить новый |
| Только чтение | Fokus не создаёт и не меняет события — только показывает |
| Обновление | Каждые 15 минут (настраивается) и по кнопке «Проверить и обновить»; при ошибке сети показываются события из кэша |
| Хранение | Адрес лежит в `data/fokus.db` (и в копиях в `data/backups/`) — не отдавайте эти файлы посторонним |

## Входящие

| Что | Как |
|---|---|
| Быстро записать мысль | `q` → название → **Shift+Enter** («Во Входящие»): задача сохраняется без мастера |
| Оценить | Боковая панель → Входящие → «Оценить» у строки (или `q` → **Enter**: сразу мастер) |
| Пока не оценена | Задача не получает балла, не попадает в группы и в «Сегодня», не переносится — «фильтры» она проходит только через мастер |

## Горячие клавиши

| Клавиша | Где | Что делает |
|---|---|---|
| `q` | везде | Открыть композер «Добавить задачу» |

## Подключение к Claude (MCP)

Fokus умеет работать как MCP-сервер: Claude Desktop, Claude Code или агент «Мир» могут добавлять задачи через мастер
из 6 вопросов, смотреть «Сегодня», отмечать «готово». Ничего устанавливать не нужно — `mcp_server.py` на стандартной библиотеке.

| Где | Как подключить |
|---|---|
| Claude Desktop | `cd ~/Projects/fokus && python3 mcp_server.py --install`, затем перезапустить Claude Desktop (старый конфиг сохраняется рядом как `.bak`) |
| Claude Code | `claude mcp add fokus -- python3 ~/Projects/fokus/mcp_server.py` |
| Вручную / другой клиент | `python3 mcp_server.py --config` печатает JSON для `mcpServers` |

Как это работает: MCP-сервер ходит в API Fokus на `127.0.0.1:4321`; если Fokus не запущен, запускает `server.py` сам
(выключить: `FOKUS_MCP_AUTOSTART=0`). Инструменты: `fokus_today`, `fokus_add_task`, `fokus_preview`, `fokus_board`, `fokus_done`,
`fokus_today_add`, `fokus_reevaluate`, `fokus_move`, `fokus_review`, `fokus_journal` и др.; промпт `fokus_wizard` — сценарий вопросов для агента.

Пример диалога: «добавь в Fokus задачу: позвонить в налоговую» → Claude задаёт 6 вопросов → показывает группу и балл → сохраняет → предлагает поставить в «Сегодня».

## Если что-то не работает

| Проблема | Решение |
|---|---|
| «Fokus не запустился» / порт занят | Узнать процесс: `lsof -i :4321`; остановить его или запустить с другим портом: `FOKUS_PORT=4322 ./Fokus.command`. Подробности — в `data/server.log` |
| «Нужен Python 3» или macOS предлагает установить инструменты разработчика | В Терминале: `xcode-select --install`, дождаться установки, запустить снова |
| «Fokus.app повреждён» / «не удаётся проверить разработчика» | Карантин после zip: правый клик по `Fokus.app` → «Открыть», либо Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно», либо `xattr -dr com.apple.quarantine Fokus.app` |
| `Fokus.app` ничего не делает | Проверить права: `chmod +x Fokus.app/Contents/MacOS/Fokus`; запустить из Терминала `./Fokus.app/Contents/MacOS/Fokus` и прочитать сообщение |
| «Fokus.command не может быть открыт» / открывается как текст | `chmod +x ~/Projects/fokus/Fokus.command`; при жалобе на разработчика — правый клик → «Открыть» или `xattr -d com.apple.quarantine Fokus.command` |
| «Рядом с Fokus.app нет server.py» | `Fokus.app` скопировали из папки проекта. Верните его обратно; ярлык — только ссылка (`ln -s`) |
| Окно открылось, страница пустая или «Сервер не отвечает» | Подождать пару секунд и обновить (`⌘R`); если не помогает — кликнуть по иконке Fokus снова (сервер перезапустится) |
| Окно открылось как обычная вкладка, хотя Chrome есть | Проверить: `open -Ra "Google Chrome"` в Терминале должен молча завершиться; задать явно: `FOKUS_BROWSER="Google Chrome"` |
| Календарь: «ошибка загрузки» | Проверить адрес (должен начинаться с `https://calendar.google.com/calendar/ical/` и заканчиваться `basic.ics`), интернет; нажать «Проверить и обновить» |
| Хочу начать с чистой базы | Остановить Fokus, переименовать `data/fokus.db` (копии остаются в `data/backups/`) |
| Как остановить | Настройки → «Выключить Fokus»; или `Fokus.command` → `s`; или `Ctrl+C` в окне Терминала |

## Правила

| Правило | Пояснение |
|---|---|
| Пациенты — только номера tomedo | Никаких имён в названиях, заметках, журнале и тестах. Подсказка есть в поле названия |
| Календарь — только чтение | Fokus ничего не пишет в Google Календарь. Телефон, Мир, Todoist — позже |
| Сервер только локальный | Слушает 127.0.0.1; запрос с чужого сайта (другой `Origin`) → 403 |
| Удаление мягкое | Задача получает `status=deleted`, журнал сохраняется |
| Единственный источник правды | [AGENTS.md](AGENTS.md): если код расходится с ним — ошибка в коде |
