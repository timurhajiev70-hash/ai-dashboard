## Вывод

| Вопрос | Ответ |
|---|---|
| Закрывает ли какая-то основа задачу целиком? | Нет, ни одна |
| Что ближе всего | Homepage: единственная панель, но даёт только карточки |
| Что всё равно пишется с нуля | Матрица «инструмент × система», подбор исполнителя (recommender), экспорт/импорт, авторизация, русский интерфейс |
| Выбранная архитектура | Собственный минимальный Node.js-сервер без зависимостей + одна страница (см. [SPEC.md](SPEC.md)) |
